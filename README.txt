SALES COMBAT — PWA PACKAGE

Files:
- index.html            Main app
- manifest.webmanifest  PWA installation metadata
- sw.js                 Offline caching/service worker
- icons/                App icons for iPhone/PWA installation

HOW TO USE:
1. Upload the entire contents of this folder to a web host.
2. Make sure the site is served over HTTPS.
3. Open the site's index.html URL in Safari on iPhone.
4. Tap Share -> Add to Home Screen -> Add.
5. Launch Sales Combat from the Home Screen.

IMPORTANT:
A PWA must be served from a web origin (HTTPS, or localhost during development).
Opening index.html directly from Files does not provide the full PWA installation experience.

The app itself does not require a server-side backend for the current built-in drills.
